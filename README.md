# DC's Free Love
Free love, man! Because queer folks have existed for as long as folks have existed.

## Description
This mod aims to expand the gender presentation available in Old World. It will have several features,
including but not limited to:
* Gay marriages
* Changing gender presentation
* Changing orientation

## Current Functionality
* Change the orientation of your leader or their descendants via a no cost mission.
* Gay characters will be presented with gay/bisexual characters.
* Bisexual characters will be presented with a mix of all three orientations.

## Planned Functionality
* Changing gender presentation
* Asexual, aromantic, and straight traits

## Installation
Either install via steam (mod.io in the future) or download and unzip the mod into your 'mods' folder.

## Refence Code Usage
Refernce code, available in your steam install under 'Reference', is used and modified in this project. Modified and unmodified code are marked via `#region`.
